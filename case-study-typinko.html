Typinko

Typinko is a desktop overlay incremental game where you type to earn points and unlock upgrades. The game is designed to be played in the background while doing other tasks on your computer, providing a fun and rewarding experience for typists of all skill levels.

Design Goal

The goal of this project is to create a balanced and mechanically deep incremental game, that is fun to both actively play and passively progress in the background. This game is also a passion project for me, as I've been an avid typist and keyboard builder for many years, and I've also been a fan of idle games for a long time, so I wanted to combine these two interests into a single project.

Additionally this project is to have a higher standard for polish and presentation than my previous projects, since I plan to eventually release on Steam.

My Role

I am the sole developer on this project, responsible for all aspects of design, programming, art, and sound. This project has a focus on mechanics and systems design, but not at the expense of presentation and polish.

  • Designed and implemented core gameplay mechanics.
  • Created all art assets, including UI elements and animations, to ensure a cohesive visual style.
  • Created Godot addon that uses the Windows API to grab keyboard inputs for progression based on WPM.

Hurdles

Production Phase

Creating the WPM hook was a significant technical challenge, as it required interfacing with the Windows API to capture keyboard inputs globally, even when the game is running in the background. This involved researching and implementing a custom Godot addon that could hook into the Windows input system.
